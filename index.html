Boby Agent

A personal assistant, built as a learning project.

Boby Agent is a private, single-user assistant that runs on its owner's own computer. Every morning it researches the latest technology news, writes a short podcast script, reads it aloud with a local text-to-speech voice, and uploads the episode as a private video to its owner's own YouTube channel, so it can be listened to on the go.

It is not a public service: nobody else can sign in to it, and it does not collect data from anyone.

How it uses Google

Boby Agent uses the YouTube API Services with a single permission, youtube.upload, which lets it upload videos to its owner's channel. It cannot read, modify or delete existing videos.
