Privacy policy

Boby Agent · Last updated: 16 November 2026

Who uses this app

Boby Agent is a personal tool used only by its owner. It is not offered to the public.

What Google data it accesses

With its owner's consent, Boby Agent requests one Google permission: https://www.googleapis.com/auth/youtube.upload. It uses it only to upload its owner's own podcast episodes as private videos to its owner's own YouTube channel. It does not read, collect, analyse or store any other Google or YouTube data.

Where data is stored

The authorisation token issued by Google is stored only on the owner's computer. It is never sent to anyone other than Google, never shared and never sold. No analytics, advertising or tracking of any kind is used.

Third-party services

Boby Agent uses the YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Podcast scripts are generated with Anthropic's Claude API from public news; they contain no Google user data.

Revoking access

Access can be revoked at any time from the Google account security settings, at myaccount.google.com/permissions. Deleting the token file on the owner's computer also stops all uploads.
